# ATML VS Code Extension — Develop

## Prereqs

- Node.js 18+ and npm
- VS Code ^1.85.0
- (Optional) `vsce`: `npm install -g @vscode/vsce`
- ATML compiler: `../compiler/atmlc.py` via Python 3, or an `atml` binary on `PATH`.

## Install + compile

```sh
cd vscode-atml
npm install
npm run compile   # runs tsc -p ./  -> out/extension.js
```

Type-check only:

```sh
npx tsc --noEmit -p ./
```

## Debug (F5)

1. Open `vscode-atml/` in VS Code.
2. Press `F5` (Run Extension / Extension Development Host).
3. In the new window, open or create a `.atml` file.
4. Run **ATML: Build to HTML** (`Ctrl+Shift+B`) or **ATML: Preview Animation** from the Command Palette.

## Package + install the .vsix

```sh
cd vscode-atml
npm install && npm run compile
vsce package        # produces atml-1.1.1.vsix
code --install-extension atml-1.1.1.vsix
```

Manual install alternative: in VS Code, **Extensions view → `...` menu →
Install from VSIX…** and pick the `.vsix`.

## Connect the compiler (manual steps)

The build command resolves the compiler as:

1. `atml.compilerPath` setting (file path to binary or `atmlc.py`).
2. `compiler/atmlc.py` next to the extension or at the workspace root's `compiler/`.
3. `atml` on `PATH`.

To point at a custom compiler:

1. Open Settings → search `atml.compilerPath`.
2. Set it to e.g. `/home/shinuji/atml/compiler/atmlc.py` or `/usr/local/bin/atml`.
3. Run **ATML: Build to HTML** and check **Output > ATML**.

`*.py` compilers are invoked as `python3 <script> build <file> -o dist/<name>.html`;
binaries as `<bin> build <file> -o dist/<name>.html`.
